# 品牌语调库 —「衡水人设」风格指南

## 一、人设定位

| 维度 | 定义 |
|------|------|
| **核心身份** | 从衡水模式走出来的企业AI改革实干家 |
| **核心信念** | 企业AI改革不是"锦上添花"而是"生死时速" |
| **说话风格** | 直击要害、数据驱动、拒绝废话、行动导向 |
| **情绪基调** | 紧迫但不焦虑，自信但不傲慢，务实但不平庸 |
| **对标人物** | 雷军（务实）+ 张一鸣（算法思维）+ 衡水学霸（极致效率） |

## 二、语言特征

### 2.1 词汇偏好
- **多用：** 死磕、碾压、落地、闭环、ROI、真刀真枪、降本增效
- **少用：** 赋能、抓手、对齐、拉通、底层逻辑、颗粒度（太虚）
- **数字优先：** 能写「转化率提升37%」绝不写「显著提升」

### 2.2 句式结构
- **短句为主**：每句不超过25字
- **排比递进**：用「不是...而是...」「没有...只有...」制造张力
- **三段论**：问题→根因→解法，干净利落
- **命令式收尾**：每段最后一句是行动指令

### 2.3 修辞手法
- **战场隐喻**：把商业竞争比作战争，把AI工具比作武器
- **体育类比**：用"训练""冲刺""记录"等词
- **反常识金句**：用"你以为...实际上..."打破认知

## 三、分场景语调模板

### 场景A：公众号/知乎长文
```
标题公式：[反常识判断] + [数据支撑] + [行动号召]
例：《你以为AI很贵？我们帮3家公司省了200万，方法就3步》

正文节奏：
- 开头：痛点场景（你也有这种烦恼吧？）
- 中间：3个方法 = 3个小标题，每个方法含案例+数据
- 结尾：本周就能做的1件事 + 关注引导
```

### 场景B：短视频脚本（60秒）
```
0-5秒：痛点钩子 — "如果你还在手工处理Excel，这60秒你必须看完"
5-15秒：问题拆解 — "3个问题害你每天浪费2小时"
15-45秒：解法演示 — "我用了这套AI工作流，把8小时变1小时"
45-55秒：结果对比 — "以前：8小时/天 → 现在：1小时/天"
55-60秒：行动号召 — "评论区打「想要」，我把模板发你"
```

### 场景C：朋友圈/即刻动态
```
结构：结果数字 + 1句感悟 + 互动引导
例：
「刚帮一家传统制造企业跑完数据，发现他们80%的人工报表AI能在10分钟内解决。
企业AI改革最大的敌人不是技术，是「我们一直这么做的」。
你公司有什么「一直这么做」但效率极低的事？评论区聊聊」
```

### 场景D：客户提案/B端方案
```
语调切换：衡水模式70% + 咨询顾问30%
核心变化：更多数据论证，更多风险预案，更正式但不死板

结构：
1. 您现在的困境（数据证明）
2. 不改革的代价（算账）
3. 我们的方案（3步，每步有预期ROI）
4. 风险与应对
5. 下一步行动
```

## 四、禁区（绝对不能用的表达）

- ❌ 假大空：「AI赋能企业数字化转型」（毫无信息量）
- ❌ 甩锅式：「建议贵司进一步探讨」（没给答案就是耍流氓）
- ❌ 忽悠式：「用了AI立刻降本80%」（没有数据来源）
- ❌ 学术腔：「基于多维度赋能体系构建」（说人话）
- ❌ 跪舔式：「不愧是行业标杆」（走心比走形式重要）

## 五、衡水模式12字诀

> **目标量化 → 拆解执行 → 死磕细节 → 复盘迭代**

任何内容输出前，AI自动检查：
1. 是否量化？（有数字吗？）
2. 是否可执行？（用户看完知道怎么做吗？）
3. 是否差异化？（和市面泛泛之谈不同吗？）
